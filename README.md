# 📊 Dashboard de Melhoria Contínua

Repositório destinado à apresentação visual de um dashboard desenvolvido para acompanhamento de indicadores operacionais, análise de movimentação e identificação de desvios entre períodos.

O dashboard reúne indicadores mensais e semanais em uma interface executiva e interativa, facilitando a visualização dos resultados e apoiando a tomada de decisão.

## 🎯 Principais funcionalidades

- Acompanhamento da movimentação atual
- Comparação com a meta operacional
- Evolução mensal e semanal
- Identificação do maior aumento entre meses
- Análise consolidada dos resultados
- Ranking de cidades com maior movimentação
- Filtros por mês, sigla, cidade e status
- Consulta detalhada dos dados

## 🖥️ Visão geral

A visão geral apresenta os principais indicadores do período, a evolução da movimentação, o resumo mensal e o ranking das cidades com os maiores resultados.
